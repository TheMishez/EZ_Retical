Import a CS2 crosshair code

Codes come from public pro-crosshair lists (csdb.gg, wecoach.gg). Pros change crosshairs often, so these may be out of date. Sizes are converted from CS2 units to pixels using your game’s screen height; if a crosshair looks too big or small next to CS2, nudge the calibration slider.

Your crosshair is drawn as the cursor. Gridshot: click the three targets. Flick: one small target at a time. Tracking: hold left mouse on the moving target. Sensitivity applies while the mouse is captured; Esc releases it and stops the run. The daily seed gives everyone the same target sequence for the day (scores are stored locally).

Compatibility

The crosshair is a separate transparent window drawn on top of everything. It never touches the game process. It only shows over games running in borderless windowed or windowed mode, not exclusive fullscreen. The input hook is only started while an animation other than None is selected.
